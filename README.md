### README

#### Описание проекта
Проект представляет собой автоматизированные тесты для работы с системой управления задачами Jira (edujira.ifellow.ru). Тесты охватывают сценарии авторизации, создания задач, проверки их статусов и изменения статусов задач.

---

#### Структура проекта
Проект состоит из нескольких классов, разделенных на пакеты `pages` и `pagesTest`:
- **`pages`**: Содержит классы для работы с элементами страниц Jira.
- **`pagesTest`**: Содержит тестовые классы, которые используют методы из `pages` для выполнения тестов.

---

#### Классы и их функциональность

##### 1. **`AuthPage`**
Класс для работы с авторизацией в системе.
- **Методы**:
    - `login(String log, String pass)`: Авторизация пользователя.

##### 2. **`ChecksTask`**
Класс для проверки элементов на странице задач.
- **Методы**:
    - `isUserProfileDisplayed()`: Проверка отображения профиля пользователя.
    - `isTitleExist(String title)`: Проверка заголовка задач.

##### 3. **`CreateTask`**
Класс для создания задач и изменения их статусов.
- **Методы**:
    - `createTask(String taskTheme, String description)`: Создание новой задачи.
    - `statusChange()`: Изменение статуса задачи.

##### 4. **`JiraTask`**
Класс для работы с деталями задачи.
- **Методы**:
    - `statusCheck()`: Получение статуса задачи и версии.

##### 5. **`TestPage`**
Класс для работы с проектами и поиска задач.
- **Методы**:
    - `projectPage()`: Переход на страницу проекта.
    - `searchText(String text)`: Поиск задачи по тексту.
    - `countTask()`: Подсчет количества задач.

##### 6. **`HWTest`**
Тестовый класс, содержащий сценарии тестирования.
- **Методы**:
    - `loginTest()`: Проверка авторизации.
    - `projectPageTest()`: Проверка страницы проекта.
    - `taskTestSelenium()`: Проверка задачи `TestSeleniumATHomework`.
    - `CreateJiraTask()`: Создание новой задачи.
    - `ChangeStatus()`: Изменение статуса задачи.

---

#### Задание
Проект реализует следующий сценарий:
1. Авторизация в системе edujira.ifellow.ru.
2. Переход в проект “Test”.
3. Проверка общего количества задач в проекте.
4. Проверка статуса и версии задачи `TestSeleniumATHomework`.
5. Создание новой задачи (бага) и изменение её статуса до закрытого.

---

#### Запуск тестов
1. Убедитесь, что установлены зависимости:
    - Selenide
    - JUnit 5
    - Allure
2. Запустите тесты с помощью команды:
   ```bash
   mvn clean test
   ```
3. Для просмотра отчета Allure выполните:
   ```bash
   mvn allure:"serve"
   ```

---

#### Настройка
- В файле `config.properties` укажите логин и пароль для авторизации:
  ```properties
  login=your_login
  password=your_password
  ```
