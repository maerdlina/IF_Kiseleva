## Описание проекта

В проекте реализованы тесты для API Rick and Morty и ReqRes, которые проверяют корректность данных и функциональность API.

## Задание

### Задача 1: Погружение в API

1. **Получение информации о персонаже Морти Смит:**
    - Используя API, получить данные о персонаже по имени "Morty Smith".
    - Из ответа выбрать последний эпизод, в котором появлялся Морти.

2. **Получение данных о последнем персонаже:**
    - Из списка персонажей последнего эпизода получить данные о последнем персонаже.
    - Получить информацию о местонахождении и расе этого персонажа.

3. **Сравнение данных:**
    - Проверить, совпадают ли раса и местонахождение последнего персонажа с Морти. Если данные не совпадают, это допустимо.

### Задача 2: Углубление в API

1. **Создание теста для API ReqRes:**
    - Создать JSON файл с данными пользователя: `{ "name": "Potato" }`.
    - Написать тест для создания пользователя (HTTP метод POST) с телом запроса, где `name` заменяется на "Tomato", а также добавляется поле `job` с значением "Eat maket".
    - Проверить, что сервер возвращает статус 201 и что полученный ответ содержит корректные значения для ключей `name` и `job`.

## Структура проекта

- **config/**: Конфигурационные файлы и классы для загрузки параметров.
- **handlers/**: Обработчики ошибок и кастомные классы для интеграции с Allure.
- **pages/**: Классы для работы с API и выполнения запросов.
- **steps/**: Шаги для Cucumber тестов, реализующие логику сценариев.
- **webHooks/**: Настройки логирования для запросов и ответов.
- **features/**: Файлы с описанием сценариев на языке Gherkin.

## Используемые технологии

- **Java 17**
- **RestAssured**
- **Selenide**
- **Cucumber**
- **Allure**

## Запуск тестов

1. Настройте файл конфигурации `config.properties` с необходимыми параметрами.
2. Запустите тесты с помощью команды:
```bash
mvn clean test
```
3. Получить Allure отчет:
```bash
mvn allure:"report"
```
4. Получить отчет Allure и отобразить его в браузере:
```bash
mvn allure:"serve"
```

## Примечания

- Все тесты должны проходить успешно (зеленые).
- В случае возникновения ошибок, они будут логироваться с деталями для диагностики.
