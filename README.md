### README

#### Описание проекта
Проект представляет собой автоматизированные тесты для работы с системой управления задачами Jira (edujira.ifellow.ru). Тесты охватывают сценарии авторизации, создания задач, проверки их статусов и изменения статусов задач.

---

#### Задание
Проект реализует следующий сценарий:
1. Авторизация в системе edujira.ifellow.ru.
2. Переход в проект “Test”.
3. Проверка общего количества задач в проекте.
4. Проверка статуса и версии задачи `TestSeleniumATHomework`.
5. Создание новой задачи (бага) и изменение её статуса до закрытого.

---

### Технологии

* Java 17
* JUnit 5
* Allure
* Selenide
* Maven

---

#### Запуск

1. Запустите тесты с помощью команды:
   ```bash
   mvn clean test
   ```
2. Для формирования отчета Allure выполните:
   ```bash
   mvn allure:"report"
   ```
3. Для формирования и просмотра отчета Allure в браузере выполните:
   ```bash
   mvn allure:"serve"
   ```
---

#### Настройка
- В файле `config.properties` можно поменять логин и пароль для авторизации:
  ```properties
  login=your_login
  password=your_password
  ```
